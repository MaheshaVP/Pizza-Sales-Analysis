# Pizza Sales Analysis Dashboard

## 📌 Overview
Developed an interactive Pizza Sales Dashboard using SQL, Power Query, and Power BI to analyze sales performance, customer ordering behavior, product performance, and revenue trends. The dashboard provides actionable insights to support business decision-making and sales optimization.

## 🛠️ Tools Used
- SQL
- Power Query
- Power BI
- Data Modeling
- DAX

## 📊 Key Metrics
- Total Revenue: 817.86K
- Average Order Value: 38.31
- Total Pizzas Sold: 49,574
- Total Orders: 21,350
- Average Pizzas per Order: 2.32

## 📈 Dashboard Features
- Revenue Analysis
- Daily & Monthly Order Trends
- Sales by Pizza Category
- Sales by Pizza Size
- Best & Worst Selling Pizzas
- Top & Bottom Products by Revenue
- Top & Bottom Products by Quantity
- Top & Bottom Products by Orders
- Interactive Filters and Slicers

## 🔍 Key Insights
- Classic pizzas generated the highest sales and orders.
- Large-size pizzas contributed the highest share of revenue.
- Orders were highest on weekends, particularly Friday and Saturday evenings.
- January and July recorded the highest order volumes.
- The Thai Chicken Pizza generated the highest revenue.
- The Brie Carre Pizza recorded the lowest sales performance.
